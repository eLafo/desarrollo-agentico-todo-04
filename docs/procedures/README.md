# Procedimientos

Cómo se trabaja en el repositorio. Como `knowledge/`, describe lo vigente: un cambio que modifica un procedimiento lo actualiza.

## Siempre

- [conventions.md](conventions.md): capas, patrones del repositorio y rúbricas de los juicios de la verificación. Un caso no lo cambia salvo que su issue lo pida.

## Según la tarea

- [development.md](development.md): el entorno, la base de datos, los tests de Go y de navegador, los gates y la CI.
  - Cuando haya que arrancar la aplicación o ejecutar tests
  - Cuando se cambie un comando, una dependencia, una variable de entorno o la CI
  - Cuando un test falle por el entorno y no por el código
