# Historia

Qué pasó, caso a caso. La escribe la skill `document` al cerrar cada caso del workflow `adw`, y viaja en el PR con el código. No se reescribe: un caso no corrige los documentos de otro.

## Según la tarea

- [changes/README.md](changes/README.md): el documento de cierre de cada caso, con las condiciones en que conviene leerlo.
  - Cuando se trabaje sobre código que ya cambió un caso anterior
  - Cuando se investigue por qué algo es como es
- [decisions/README.md](decisions/README.md): las preguntas con opciones que respondió el humano, con su contexto y su elección.
  - Cuando el encargo toque algo que el humano ya decidió
